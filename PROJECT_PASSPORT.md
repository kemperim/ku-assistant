## Цель проекта

Снизить нагрузку на приёмную комиссию и дать абитуриентам быстрый канал получения ответов по официальным материалам университета.

## Задачи проекта

- Загрузка и хранение документов приёмной комиссии.
- Разбор PDF, DOCX и TXT-файлов.
- Разбиение документов на фрагменты.
- Создание эмбеддингов через Ollama.
- Поиск релевантных фрагментов по вопросу пользователя.
- Генерация ответа через Groq API только на основе найденного контекста.
- Отображение ответа в веб-интерфейсе.
- Поддержка запуска через Docker Compose.

## Используемые технологии

- Python 3.11 в Docker-контейнере.
- FastAPI.
- Uvicorn.
- Ollama.
- nomic-embed-text.
- Groq API.
- FAISS.
- pdfplumber и pypdf для PDF.
- python-docx для DOCX.
- Docker Compose.

## Архитектура

1. Пользователь задаёт вопрос в веб-интерфейсе.
2. FastAPI получает запрос на endpoint `/ask`.
3. Вопрос преобразуется в embedding через Ollama.
4. VectorStore ищет похожие фрагменты документов.
5. RAGEngine формирует контекст из найденных фрагментов.
6. Groq LLM получает системный prompt, контекст и вопрос.
7. Пользователь получает краткий ответ и список источников в API-ответе.

## Основные файлы

- `app/main.py` - FastAPI-приложение и API endpoints.
- `app/rag_engine.py` - RAG-логика, синхронизация, поиск и генерация ответа.
- `app/vectorstore.py` - хранение эмбеддингов и векторный поиск.
- `app/parser.py` - парсинг документов.
- `app/gdrive.py` - загрузка документов из Google Drive.
- `static/index.html` - пользовательский чат-интерфейс.
- `cli.py` - CLI-команды для индекса.
- `docker-compose.yml` - запуск проекта.

## API

- `GET /` - веб-интерфейс.
- `POST /ask` - вопрос к помощнику.
- `POST /sync` - синхронизация и индексация документов.
- `GET /status` - статус индекса.
- `GET /health` - проверка доступности сервиса.
- `GET /docs` - Swagger UI.

## MVP-функциональность

В рамках MVP реализованы:

- чат-интерфейс для абитуриента;
- индексация локальных документов;
- опциональная синхронизация Google Drive;
- поиск по документам;
- генерация ответов по найденному контексту;
- запуск через Docker Compose.

## Ограничения MVP

- Качество ответа зависит от качества и актуальности документов в папке `docs/`.
- Стоимость обучения, сроки и правила поступления могут изменяться; для финального решения абитуриент должен сверять данные с ku.edu.kz, apply.ku.edu.kz и приёмной комиссией.
- Без контейнера Ollama индексация не выполняется.
- Без `GROQ_API_KEY` генерация ответов через LLM не работает.
- Проект не заменяет официальную консультацию приёмной комиссии.
